01 / The question

Same task.
A richer distribution.

Push-T offers a focused setting for learning contact-rich manipulation. Push Any Letter expands the object distribution to all 52 uppercase and lowercase ASCII letters, with different contours, holes, symmetries, and contact opportunities.

The aim is to study performance across letter shapes and target angles, instead of relying on a single aggregate score for one object. Different starts and planner seeds provide multiple successful solutions for each letter–orientation pair.

03 / Research directions

One environment.
Three ways to study learning.

Imitation learning

Train on planner demonstrations and compare behavior cloning, diffusion policy, flow matching, and an ACT-style model. Inspect success by letter and angle, with both state and image observations.

Reinforcement learning

Use the Gymnasium environment to learn through interaction, or initialize from demonstrations and fine-tune. Study sample efficiency, exploration, and robustness across object geometries.

World models

Compare single-frame and four-frame state models without velocity or task goals. Inspect prediction errors and recorded rollouts in the world-model report.

04 / Evaluation

Measure where
generalization breaks.

Report per-letter and per-angle behavior alongside overall success. More varied geometry makes failure modes easier to locate.

  • Training distribution. All 10 demonstrations for each of the 52 × 12 letter–orientation conditions.
  • Unseen orientations. The provided evaluation uses 10 fixed unseen angles and fresh starts across all 52 letters: 520 episodes, with a 95% geometric coverage threshold.
  • Controlled physics. Released demonstrations and baseline evaluations use block friction 1.4, pusher friction 0.6, and damping 0.12. Each accepted episode is independently replay-validated.
  • Scope of the evidence. Center-only goals do not establish arbitrary-position generalization. New fonts and held-out letters require separate splits and experiments. The V1 state-policy results below report performance within this scope.

02World models 世界模型V1 · State dynamics+
No velocity · No target · V1 data

Does history help
predict motion?

We omit velocity from the input and use four recent states and past actions to supply motion context. We expected this history to help recover movement trends. On V1, the four-frame model instead has larger rollout errors than the single-frame control.

25.50 vs 41.69

Single-frame vs four-frame · position error in pixels

100-step prediction · held-out V1 trajectories

Inputs and prediction. Both models receive letter identity, pusher and object positions, object orientation encoded as sine/cosine, and the current absolute pusher-target action. The history model adds the preceding three states and actions. Both predict the next state; neither receives velocity, a task goal, reward, or images.

Data split. V1 contains 6,240 episodes and 4,736,343 transitions in total. Within each letter–angle condition, slots 00–07 train, 08 validates, and 09 tests: 4,992 / 624 / 624 whole episodes. Test letters and goal angles are familiar; trajectories are held out.

Matched training. Three 256-unit MLP layers, a letter embedding, and 30,000 updates per model, with the same sampling seed. The objective combines one-step prediction with a five-step rollout term every fourth update. One seed was tested. Checkpoints are selected by 50-step validation position and angle error.

03Reinforcement learning 强化学习Online PPO · Training+
Online interaction · No demonstrations

One policy.
Every letter, any angle.

We train a shared PPO policy on all 52 letters, with target orientations sampled continuously around the full circle. The policy learns through contact with the simulator. It uses no demonstration dataset and no imitation-policy initialization.

200

Parallel environments · one shared policy

50 CPU workers × 4 environments · GPU learner

Training started on 26 October 2026 (UTC+8). This is a state-based experiment with a budget of 51.2 million environment transitions and seed 42. Training is in progress; no final RL success rate is available.

A different experiment identifier. Dataset V1, V2 and V3 describe offline demonstration releases. Online RL samples its own experience, so those labels do not apply here. We record the environment, reward, code revision, font, seed and interaction budget to make each run reproducible.

State and control. A 72-dimensional input encodes letter identity, object and pusher poses and velocities, goal pose, relative positions and overlap. The action is a two-dimensional relative pusher waypoint. One network controls all letters; there is no per-letter policy.

Continuous goals, bounded starts. The target remains centered. Its angle is uniform over 0–360°. Full-distribution starts cover feasible positions and random object angles; the complete glyph starts at least 48 pixels from the inner walls. Contact friction remains 1.4.

Shared geometric reward

Reward alignment, respect symmetry.

Let C be area coverage, d the object-centroid distance to its goal, and g the pusher's gap to the glyph surface. Distances are normalized by the 156-pixel glyph size. Every letter uses the same potential and reward:

Φ(s) = 4 C(s) − 2 d(s) − 0.5 g(s)
r = 20 · success − 0.01 − 0.001 ‖a‖²
    + 0.999 Φ(s_next) − Φ(s)

The centroid term guides motion before overlap; coverage rewards alignment; the gap term helps the pusher approach. We use geometric overlap instead of a raw angle error, so equivalent orientations of symmetric glyphs are treated consistently. Success means reaching 95% coverage within 2,400 steps.

The potential is zero at absorbing success. Time limits retain the terminal observation for value bootstrapping. The shaping discount matches PPO's discount; the time and control penalties are explicit task costs.

Practice gets harder. Evaluation stays fixed.

52 monitoring cases · 520 final cases

From the start, 25% of episodes use full-distribution resets. The remaining episodes start nearer the goal, with position and angle difficulty expanding over the first 20 million transitions. This curriculum is intended to help a randomly initialized policy learn contact before long rearrangements.

We log PPO losses and rolling training success separately from independent evaluation. A fixed set of 52 full-distribution cases, one per letter, is evaluated at initialization and every 2.56 million transitions. The final policy also receives 520 separately seeded cases with new starts and continuous target angles. These are familiar-letter tests; new fonts and unseen letters remain outside this run.

There is no finite training-angle grid defining “seen” and “unseen” for this online run. Fresh-state evaluation is the relevant measure. Its cases differ from the imitation-learning benchmark above, so the scores will not constitute a matched-case comparison. Curves and rollout examples will be reported from saved measurements.
