01 / The question

Same task.
A richer distribution.

Push-T offers a focused setting for learning contact-rich manipulation. Push Any Letter expands the object distribution to all 52 uppercase and lowercase ASCII letters, with different contours, holes, symmetries, and contact opportunities.

The aim is to study performance across letter shapes and target angles, instead of relying on a single aggregate score for one object. Different starts and planner seeds provide multiple successful solutions for each letter–orientation pair.

03 / Research directions

One environment.
Three ways to study learning.

Implemented baselines

Imitation learning

Train on planner demonstrations and compare behavior cloning, diffusion policy, flow matching, and an ACT-style model. Inspect success by letter and angle, with both state and image observations.

Proposed extension

Reinforcement learning

Use the Gymnasium environment to learn through interaction, or initialize from demonstrations and fine-tune. Study sample efficiency, exploration, and robustness across object geometries.

Proposed extension

World models

Use state–action transitions and RGB sequences to learn contact dynamics. Evaluate multi-step predictions across letters and orientations, then test whether a learned model supports successful planning.

RL and world-model protocols are research directions, not released benchmark results. This project currently provides the environment, demonstrations, and imitation-learning baseline code.

04 / Evaluation

Measure where
generalization breaks.

Report per-letter and per-angle behavior alongside overall success. More varied geometry makes failure modes easier to locate.

  • Training distribution. All 10 demonstrations for each of the 52 × 12 letter–orientation conditions.
  • Unseen orientations. The provided evaluation uses 10 fixed unseen angles and fresh starts across all 52 letters: 520 episodes, with a 95% geometric coverage threshold.
  • Controlled physics. Released demonstrations and baseline evaluations use block friction 1.4, pusher friction 0.6, and damping 0.12. Each accepted episode is independently replay-validated.
  • Scope of the evidence. Center-only goals do not establish arbitrary-position generalization. New fonts and held-out letters require separate splits and experiments. The V1 state-policy results below report performance within this scope.

Seen means training starts. The monitoring set contains one recorded training initial state per letter. It is a 52-case subset, not an evaluation over all 6,240 demonstrations. The policy controls each rollout in closed loop.

Unseen means new angles and starts. All 52 letters remain familiar. Ten fixed angles, at least 3° from the training grid, yield 520 fresh test tasks. Curves use 52 fixed cases; the full final test uses all 520. These are different samples, so their percentages need not match.

One shared success rule. Reach at least 95% geometric coverage within 2,400 control steps. Goals stay centered, the font and physics stay fixed, and all ten demonstrations per condition are used for training. The final update count was fixed in advance, without selecting checkpoints on test success.

Next experiment · planned, not yet released

More data. The same question.

10 → 100demonstrations per condition

For V2, we plan to expand each letter–orientation condition from 10 to 100 demonstrations: 52 × 12 × 100 = 62,400 trajectories. We will repeat the four-policy comparison with matched evaluation tasks, and examine how gains from additional data compare with differences between models.

ACT is strongest in the current V1 state experiment. Whether that advantage persists with ten times more data remains an open question; the current results do not separate data-scale effects from model and training choices.
